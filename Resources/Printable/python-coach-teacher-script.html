Teacher Script — Parent / Coach

Purpose: Exact words and pacing for each week. Mark “stuck” in the app when Soha needs a redo.

Weekly rhythm: 2–3 lessons · one game build · 30 min blocks · use Playground (⌘R) · pygame = Terminal or Run game window

Week 1 — Hello, Python!

“Today we're programmers. Python is how we tell the Mac what to do. No magic — just clear instructions.”

“Think of variables as sticky notes on boxes. The label is the variable name; what's inside is the value.”

“Let's build something that's yours — not a copy from a worksheet.”

If stuck: Run one line at a time in Playground. Celebrate first successful print.

Week 2 — Decisions

“Before, programs only talked. Now they listen.”

“If the condition is True, do this block. Otherwise, do that block.”

“Real apps use this idea — checking before showing something.”

Week 3 — Loops

“Loops are how games run frame after frame.”

“When you know how many times, for is cleaner than while.”

Week 4 — Functions

“Functions are like custom LEGO pieces you build once and reuse.”

“Some functions do something; some calculate and give back a value.”

Week 5 — First Games

“Games need unpredictability — that's what random gives us.”

“Walk through one round together before Soha codes solo.”

“Notice how the same patterns repeat: input, compare, update score.”

Week 6 — Science Quiz (NSB tie-in)

“Connect to Science Bowl prep — she already knows these topics! Add toss-ups from DOE practice.”

“Lists are how we store inventories, questions, and high scores.”

Sample toss-upAnswer
Gas plants release in photosynthesis?Oxygen
H2O is?Water
Speed = distance / ?Time
Powerhouse of the cell?Mitochondria
Red Planet?Mars

Week 7 — pygame

“Draw a quick sketch on paper before coding — it helps every time.”

“First run might feel slow — celebrate the window appearing!”

“Game 4 teaches state: where am I? where is the goal?”

One-time setup: pip3 install pygame

Week 8 — Final Boss

“Five minutes of planning saves an hour of debugging.”

“One feature at a time — never add sound, timer, and coins all at once.”

“This is your portfolio piece — take a screen recording when it works!”

When she's stuck — say this

  • “Read the error out loud — the last line often tells us.”
  • “Change one thing, run again.”
  • “Mark stuck in the app — we'll revisit Thursday.”
  • “Compare your code to starter code line by line.”

Progress & backup

App → Progress tab: week notes, export JSON backup, stuck list, graduation checklist.
